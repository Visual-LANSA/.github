# Visual LANSA

> Visual LANSA keeps rules and clients on one Windows desk: open the repository, pin the business rules, and leave the Windows client on the same enterprise app.

## Four Beats

1. **Name the app.** Give the Visual LANSA enterprise app a short title before you draw a client.
2. **Pin the live objects.** Keep current work on Visual LANSA repository and leave unused objects aside.
3. **Check the rules.** Read Visual LANSA business rules before you move a Windows client.
4. **Keep the pair.** Leave repository and rules on the same Visual LANSA enterprise app.
5. **Close the loop.** Clear finished rules so the next Visual LANSA visit does not start with a search.

## First Questions

**Does Visual LANSA replace every other program?**
No. Visual LANSA sits beside the editor, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate Visual LANSA profile.

**What should a new user try first?**
One small Visual LANSA repository object today, then the same business rules tomorrow.

**Does the Windows client leave the enterprise app?**
No. Visual LANSA Windows client stays with Visual LANSA business rules on that app.

**Are rules only for a finished client?**
No. Visual LANSA can hold a single rule while the rest of the client stays off the board.

## Field Note

Visual LANSA is easier to trust when the repository stays smaller than the folder it came from. A named enterprise app shows what is active, the object pins show what you will touch today, and the closing note tells the next person which rule changed.

The same loop fits a single rule, a short client, or a desk shared by two people. Open the last Visual LANSA enterprise app, finish one rule, and leave fewer scattered checks than you found.

A review should not have to guess which rule belongs to the open client. Keep that pair together inside Visual LANSA.

## One Real Pass

Pick an app that already has a name. Open it in Visual LANSA, keep only those objects on the repository, and finish one business rule you can see.
